# 節點畫布

在瀏覽器裡用 Excalidraw 畫心智圖／流程圖，畫布檔（`.excalidraw`）存在自己的電腦。AI（Claude、Google Antigravity 等）可以用指令讀取和修改同一張畫布，你的畫面會即時更新；分支可以像 Xmind 一樣收合、展開。

## 需要

- [Node.js](https://nodejs.org) LTS 版（18 以上）
- 網路：畫布畫面的程式從網路載入，離線開不起來

## 開啟畫布（Windows）

1. 把畫布檔（`.excalidraw`）**拖到「開啟畫布.cmd」上**，瀏覽器就會打開畫布。
   - 也可以雙擊「開啟畫布.cmd」，再把畫布檔拖進視窗、按 Enter。
   - 輸入一個還不存在的檔名，會建立新的空白畫布。
   - 第一次使用會自動安裝套件，要等一下。
2. 黑色視窗開著時畫布才能用，用完直接關掉它。

同時開好幾張畫布時，每張要用不同的埠：在命令列執行 `開啟畫布.cmd 畫布檔 5181`。

其他系統（macOS、Linux）用命令列：

```bash
node server.mjs 你的畫布.excalidraw 5180 --open
```

## 在畫布上編輯

- 修改會在停手約半秒後自動存回檔案。
- 選取節點後按 **Ctrl＋方向鍵**，可以往那個方向長出新節點並自動連線。
- 一個方框就是一個節點：文字第一行是名稱，空一行之後是說明。
- **收合分支**：點節點右邊的 **−** 收合，**＋數字** 展開（數字是藏了幾個節點）。右上角「分支」面板可以「只看主幹」「展開到第二層」「全部展開」。
  - 收合不會刪任何東西，藏起來的節點還在檔案裡。
  - 「自動排版」打勾時，收合或展開後會把看得到的節點重新排整齊；鎖定的節點不會動。不想動到你調好的位置就取消勾選。
  - 收合是在伺服器端改檔，Ctrl＋Z 復原不了；要復原就再按一次那顆鈕。
- AI 改了畫布時，畫面會自動更新，右下角會提示；可以按 Ctrl＋Z 復原 AI 的修改。

## 備份

每次 AI 用 `canvas.mjs` 修改畫布前，都會把原檔備份到畫布旁邊的 `.canvas-history/` 資料夾。

## 在不同電腦使用

- **搬工具**：把這個資料夾複製過去（`node_modules` 不用複製，第一次開啟會自動安裝）。建議放在私人 GitHub 版本庫，每台電腦 `git clone` 一份，更新時 `git pull`。
- **共用畫布**：畫布檔放在 Git 版本庫或 Google 雲端硬碟同步資料夾。同一時間只能一台電腦開著編輯，不然兩邊會互相覆蓋。
- **只用即時畫布編輯**：VS Code 的 Excalidraw 擴充套件、excalidraw.com 只在開檔時讀一次，存檔會蓋掉 AI 的修改。

## 讓 AI 操作

把 `AGENTS.md` 交給 AI（Claude 會自動讀；Google Antigravity 等工具請設成規則，或在對話一開始叫它先讀）。裡面寫了怎麼讀畫布、怎麼改、不能做什麼。

## 檔案

| 檔案 | 用途 |
|---|---|
| `開啟畫布.cmd` | Windows 一鍵開啟 |
| `server.mjs` | 本機小伺服器，負責畫面和檔案同步、收合 |
| `editor.html` | 瀏覽器裡的畫布畫面 |
| `canvas.mjs` | 讀畫布、套用修改、自動排版（AI 用的指令） |
| `AGENTS.md` | 給 AI 的操作說明 |
